# Programação Orientada a Objetos (POO)

> Projetos e exercícios da disciplina de POO, explorando os pilares da orientação a objetos com Java: encapsulamento, herança, polimorfismo e interfaces.

---

## 🗝️ Conceitos Abordados

- Encapsulamento, construtores, getters e setters
- Herança com `extends` e uso de `super`
- Polimorfismo: sobrescrita (`@Override`) e ligação dinâmica
- Classes abstratas e interfaces
- Tratamento de exceções (`try/catch/finally`)
- Coleções Java (`ArrayList`, `HashMap`)
- Modelagem UML de diagramas de classe
