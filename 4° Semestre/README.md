## 🏗️ Projetos Destaque

### 🏨 AtividadeHotel — Sistema Hoteleiro
Sistema completo de gestão hoteleira com: `Hotel`, `Quarto`, `Hospede`, `Reserva`, `Servico`, `Fatura`, `Frigobar`.

### 🐾 AtividadeP1 — Clínica Veterinária
Sistema de clínica com: `Animal`, `Pessoa`, `Cliente`, `Veterinario`, `Secretaria`, `Consulta`, `Agendamento`.

### 📋 DEVLab1 — Gestão de TCC
Sistema de alocação de trabalhos de conclusão de curso com herança: `Pessoa → Aluno`, `Pessoa → Professor → ProfessorOrientadorTCC`.

### 🚗 DEVLab4 — Gestão de Veículos
Hierarquia completa com polimorfismo: `Veiculo (abstract)` → `VeiculoPasseio`, `VeiculoTransporte`, `VeiculoUtilitario`, `CarroSedan`. Implementa 3 interfaces.

---

## 🗝️ Conceitos Aprendidos

- **Classes e Objetos**: encapsulamento, construtores, getters/setters
- **Herança**: `extends`, `super`, hierarquias de classes
- **Polimorfismo**: sobrescrita de métodos, `@Override`, ligação dinâmica
- **Classes Abstratas** e **Interfaces**
- **Tratamento de Exceções**: `try/catch/finally`, exceções customizadas
- **Coleções**: `ArrayList`, `HashMap`
- **UML**: diagramas de classe para modelagem de sistemas
