## 🎮 Projetos APC — Trabalhos em Grupo

### 🎪 Espetáculo (by Elisa)
Sistema completo de gestão de entretenimento com lógica complexa em C.

### 🔢 JacoMath (by Ithalo)
Calculadora matemática interativa com múltiplas operações aritméticas.

### 🧙 Magus Game (by Diogo)
Jogo de aventura em modo texto com 3 versões iterativas (`magus.c`, `magus_1.c`, `magus_2.c`).

### ✂️ Pedra-Papel-Tesoura (by G2)
Jogo completo com sistema de placar persistente, organizado em múltiplos arquivos:
- `PaperRockScissor.c` — lógica do jogo
- `scoreboards.c` — gestão de pontuações
- `screen.c` — interface de tela

## 🗝️ Conceitos Aprendidos

- Variáveis, tipos primitivos e operadores em C
- Estruturas condicionais (`if/else`, `switch`)
- Laços de repetição (`for`, `while`, `do-while`)
- Funções e modularização de código
- Entrada e saída com `scanf` / `printf`
- Primeiros passos com projetos multi-arquivo
