## Exercício A — Valor da compra (3 produtos, soma e média)

```
declarar p1, p2, p3, soma, media

mostrar "Digite o valor do produto 1: "
ler p1
mostrar "Digite o valor do produto 2: "
ler p2
mostrar "Digite o valor do produto 3: "
ler p3

soma = p1 + p2 + p3
media = soma / 3

mostrar "Soma da compra: "
mostrar soma
mostrar "Media da compra: "
mostrar media
```
