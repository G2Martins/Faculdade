# 6° Semestre — Teoria dos Grafos

> Fundamentos e algoritmos de grafos: representação, propriedades estruturais, coloração, percursos e caminhos mínimos. Implementações em Python com material de apoio das aulas.

---

## 📂 Estrutura

```
6° Semestre/
└── Teoria dos Grafos/
    ├── Grafo Esparso/           # Grafo com lista de adjacência
    ├── Grafo Denso/             # Grafo com matriz de adjacência
    ├── Grafo Isomorfo/          # Verificação de isomorfismo
    ├── Grafo Coloracao/         # Coloração de grafos
    ├── Algoritmo de Bellman-Ford/ # Caminho mínimo (grafos com pesos negativos)
    ├── Algoritmo de Kruskal/    # Árvore geradora mínima
    ├── Atividade 01–12/         # Exercícios semanais
    └── Material/                # 8 slides/PDFs das aulas
```

---

## 🗝️ Conceitos Aprendidos

- **Representação de Grafos**: lista de adjacência vs. matriz de adjacência
- **Propriedades**: grafo simples, completo, nulo, regular, isomorfo
- **Coloração**: número cromático, algoritmos gulosos
- **Percurso**: BFS (largura), DFS (profundidade)
- **Caminhos Mínimos**: Dijkstra, Bellman-Ford
- **Árvore Geradora Mínima**: Kruskal
