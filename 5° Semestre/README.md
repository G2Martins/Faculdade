## 🗝️ Conceitos Aprendidos

- **Algoritmos de Ordenação**: Bubble Sort, Merge Sort (O(n log n))
- **Busca**: Linear e Busca Binária (O(log n))
- **Recursão**: Fibonacci, divisão e conquista
- **Programação Dinâmica**: memoização, tabulação
- **Análise de Complexidade**: notação Big-O, custo operacional
- **Python**: listas, funções, estruturas de controle
