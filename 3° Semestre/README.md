# 3° Semestre — Estrutura de Dados & Computação Gráfica

> Semestre de especialização: implementação de estruturas de dados clássicas em C/C++ e programação gráfica com MATLAB. Inclui também desafios de plataformas externas (BeeCrowd e DIO).

---

## 📂 Estrutura

```
3° Semestre/
├── Estrutura de Dados/   # Estruturas de dados em C e C++
│   ├── Arvore/           # Árvores AVL e binárias
│   ├── Beecrowd/         # Desafios do BeeCrowd (juiz online)
│   ├── Dio/              # Desafios da plataforma DIO (C e C++)
│   ├── Fila/             # Implementações de fila
│   ├── Lista/            # Listas ligadas simples e duplamente ligadas
│   ├── Ordenaçoes/       # Algoritmos de ordenação
│   ├── Pilha/            # Implementações de pilha
│   └── Registro/         # Structs e registros em C
└── Computação Gráfica/   # Programação gráfica com MATLAB
    ├── Faculdade/        # Trabalhos acadêmicos
    └── Udemy/            # Curso complementar de MATLAB
```

---

## 🗝️ Conceitos Aprendidos

- Estruturas de dados lineares: pilha, fila, lista ligada, lista duplamente ligada
- Estruturas de dados não-lineares: árvore binária, árvore AVL
- Algoritmos de ordenação: bubble sort, insertion sort, selection sort, merge sort, quick sort
- Structs e registros em C
- Fundamentos de programação gráfica com MATLAB
- Processamento de imagens e visão computacional
