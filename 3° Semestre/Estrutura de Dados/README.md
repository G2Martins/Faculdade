# Estrutura de Dados

> Implementação das principais estruturas de dados em C, com resolução de desafios em juízes online (BeeCrowd) e na plataforma DIO. Inclui versões do professor, versões próprias e comparação entre implementações.

---

## 📂 Estrutura

```
Estrutura de Dados/
├── Arvore/        # Árvores binárias e AVL
├── Beecrowd/      # Desafios do BeeCrowd (juiz online)
│   ├── Desafio_Mate/
│   ├── Desafio_cartas_fora/
│   ├── Desafio_Fila_Recreio/
│   ├── Desafio_Ida_Feira/
│   └── Desafio_pares_impares/
├── Dio/           # Desafios da plataforma DIO
│   ├── Desafios/  # 9 desafios temáticos em C (IA, robôs, cidades inteligentes)
│   └── Cpp/       # Desafios em C++
├── Fila/          # Implementações de fila (lista e vetor)
├── Lista/         # Lista ligada simples e duplamente ligada
├── Ordenaçoes/    # Algoritmos de ordenação
├── Pilha/         # Implementações de pilha (lista e vetor)
├── Registro/      # Structs: registro_1.c, registro_2.c, registro_G2.c, registro_prof.c
└── tipagem.tldr   # Notas sobre tipos de dados em C
```

---

## 🗂️ Estruturas Implementadas

### 📚 Pilha (Stack)
Implementações usando vetor e lista ligada, com operações de `push`, `pop` e `peek`.

### 🚶 Fila (Queue)
Implementação com lista ligada, operações `enqueue` e `dequeue`.

### 🔗 Lista Ligada
- **Lista Simples**: nó com ponteiro para o próximo
- **Lista Duplamente Ligada**: nó com ponteiros para anterior e próximo

### 🌳 Árvore
- **Árvore Binária de Busca**: inserção, remoção e busca
- **Árvore AVL**: balanceamento automático com rotações simples e duplas

### 📋 Registro (Structs)
Uso de `struct` em C para modelar entidades do mundo real.
